# search-door

A small browser game: a dark hallway full of doors, one of which leads home. Knock, watch it swing, watch the little creature react. Find the way home.

## Step-by-step reasoning

1. **Constraints first.** The game must run on GitHub Pages with no build step, so it had to be plain static HTML, CSS, and JavaScript. Everything lives in a single `index.html` at the repo root — no bundler, no asset pipeline, no framework. That is the whole deploy surface.

2. **Core concept.** A row of seven doors in a candlelit hall; exactly one is the way home. Player clicks a door, it swings open with a glow, the creature hops over and reacts. Win by finding the right door.

3. **Scope decisions.** I considered adding a timer, lives, or a move limit. Cut all three: the randomly placed goal door already creates stakes, and each interaction was already juicy enough. No extra systems.

4. **Feel.** Door swing uses a CSS `rotateY` hinge; open glow uses a radial gradient. Creature hop, squash, wave, droop, and dance are handled by the Web Animations API plus CSS keyframes. Sound is a tiny WebAudio oscillator synth, so there are no audio files. Cozy lighting comes from a flickering candle glow, drifting dust, and a vignette; type uses Fraunces and Karla.

5. **Replayability.** A new goal door is chosen at random on each run, and the win screen offers a fresh knock.

## Play

Press the button, then start clicking doors until you find the way home.
